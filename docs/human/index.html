Sebas

Plataforma de bot Discord modular. Este site documenta como usar o Sebas e, principalmente, como construir módulos de terceiro pra ele.

O que é

Sebas é um bot Discord dividido em três partes (monorepo npm workspaces):

core

Processo Node/TypeScript. Recebe interactions do Discord, expõe uma admin API REST, roda os módulos em worker_threads isoladas.

panel

Dashboard Next.js. Fala com o core via HTTP (secret Bearer + header de identidade do admin).

módulos

Unidades isoladas de funcionalidade — in-tree (embutidos) ou instalados dinamicamente via marketplace, sempre a partir de um repositório git próprio.

Dois módulos de referência, ambos públicos

Servem tanto como funcionalidade real do bot quanto como exemplo completo de como escrever um módulo:

  • sebas-module-changelog-roblox — monitora RSS, formata com IA, posta no Discord. Usa controller + cron + discordCommands.
  • sebas-module-permissions — controla quem pode falar com o bot (DM/menção/ação). Usa controller + permissionGate.
Ambos os repositórios estão linkados na página Criando um módulo e em cada seção relevante da API.

Por onde começar

Se você vai só usar o painel administrativo do seu Sebas: veja Uso rápido. Se você vai escrever um módulo novo (à mão ou com ajuda de uma IA): leia Visão geral do contrato e depois Criando um módulo — a Referência de API fica pra consulta durante o desenvolvimento, não precisa ler tudo antes de começar.

Sebas

A modular Discord bot platform. This site documents how to use Sebas and, mainly, how to build third-party modules for it.

What it is

Sebas is a Discord bot split into three parts (npm workspaces monorepo):

core

Node/TypeScript process. Receives Discord interactions, exposes a REST admin API, runs modules in isolated worker_threads.

panel

Next.js dashboard. Talks to core over HTTP (Bearer secret + an admin identity header).

modules

Isolated units of functionality — in-tree (bundled) or dynamically installed via the marketplace, always from their own git repository.

Two reference modules, both public

They serve both as real bot functionality and as a complete example of how to write a module:

  • sebas-module-changelog-roblox — monitors an RSS feed, formats with AI, posts to Discord. Uses controller + cron + discordCommands.
  • sebas-module-permissions — controls who can talk to the bot (DM/mention/action). Uses controller + permissionGate.
Both repositories are linked on the Creating a module page and in each relevant API section.

Where to start

If you're just going to use your Sebas's admin panel: see Quick usage. If you're writing a new module (by hand or with an AI's help): read Contract overview then Creating a module — the API Reference is for lookup while you build, not required reading up front.
