Uso rápido

O básico do painel administrativo — sem entrar em código de módulo.

Conversar com o Sebas

  • /sebas mensagem:... — slash command, resposta ephemeral (só você vê), funciona em qualquer canal onde o bot está.
  • DM direta ou @menção num canal — conversa passiva, sujeita às regras do módulo de permissões (se instalado; por padrão só o dono do bot é respondido).

Painel: Configurações

AbaO que tem
ContaIdentidade da sessão, token do GitHub (necessário pra busca de módulos no marketplace), auto-update do próprio Sebas.
ParâmetrosOverride de persona/system prompt, temperature/max_tokens padrão, cooldown de rate limit.
OpenCodeChave da conta OpenCode Zen, ordem de prioridade de modelos gratuitos (drag-and-drop), troca automática de modelo em rate limit.
MarketplaceIntervalo de verificação de atualização de módulo instalado, auto-update por módulo.

Painel: Módulos

/modules lista todos os módulos (in-tree e instalados). /modules/marketplace busca repositórios públicos com sebas.module.json no GitHub — cards já instalados mostram "Configurar" em vez de "Instalar".

Um módulo instalado passa por: pending → dono aprova as permissões pedidas → approved → dono habilita → enabled. Dá pra desabilitar/desinstalar a qualquer momento.

Admins/subadmins

A página /admins controla quem acessa o painel e o que cada subadmin pode ver/editar (escopos como guilds:view, modules:manage, etc). Isso é diferente de quem pode falar com o bot no Discord — essa segunda parte é controlada pelo módulo permissions (se instalado), não pela página de admins.

Quick usage

The basics of the admin panel — no module code yet.

Talking to Sebas

  • /sebas message:... — slash command, ephemeral reply (only you see it), works in any channel the bot is in.
  • Direct DM or @mention in a channel — passive chat, subject to the permissions module's rules (if installed; by default only the bot owner gets a reply).

Panel: Settings

TabWhat's in it
AccountSession identity, GitHub token (needed for marketplace search), Sebas self-update.
ParametersPersona/system prompt override, default temperature/max_tokens, rate-limit cooldown.
OpenCodeOpenCode Zen account key, free-model priority order (drag-and-drop), automatic model switch on rate limit.
MarketplaceInstalled-module update-check interval, per-module auto-update.

Panel: Modules

/modules lists every module (in-tree and installed). /modules/marketplace searches public GitHub repos containing a sebas.module.json — already-installed cards show "Configure" instead of "Install".

An installed module goes through: pending → owner approves the requested permissions → approved → owner enables it → enabled. It can be disabled/uninstalled at any time.

Admins/subadmins

The /admins page controls who can access the panel and what each subadmin can see/edit (scopes like guilds:view, modules:manage, etc). That's different from who can talk to the bot on Discord — that second part is controlled by the permissions module (if installed), not the admins page.
